# Work packet and handoff

Use an existing equivalent task record when possible. An assignment is not a permission grant, a running process or accepted evidence. References should resolve to current private project records; do not copy secrets into a broadly shared packet.

## Assignment

- Stable task ID and packet revision:
- Project, requester, responsible team, actual assignee and integrator:
- Useful objective and beneficiary:
- Exact input references and revisions; source applicability and unknowns:
- Standing authority/brief reference, permitted effects and exclusions:
- Dependencies and current priority/reason/reconsideration trigger:
- Owned output paths, shared-state writer and explicit output-claim state:
- Observable acceptance, required checks and actual independence requirement:
- Model/tool choice, reason and simpler alternative:
- Aggregate time/case/resource/model-call limits, consumed counters or UNKNOWN:
- Useful stop, retry/recovery rules and uncertain-effect reconciliation:
- Actual host dispatch/call reference or unavailable; no invented liveness:

## Submission

- Exact packet revision and immutable submitted subject/revision:
- Artifact/evidence references and identities:
- Actual observations, controls and failures, separate interpretation:
- Completed work and unmet requirements:
- Effects, cleanup/recovery and uncertain completion:
- Actual cost counters or UNKNOWN, including retries/delegates:
- Known limits, next action and retained output claims:

## Review and integration

- Actual reviewer and implementers; whether independence is required/established:
- Exact reviewed submission revision, judgment and evidence:
- Findings/corrections, retained prior result and re-review boundary:
- Integrator decision and resulting source/artifact identity:
- Distinct deployment/disclosure/owner-acceptance state if applicable:

Shared updates SHALL use the project's existing revision/event contract. Reconcile stale, conflicting or missed state before resuming or retrying. No new document is needed per ordinary tool call.
